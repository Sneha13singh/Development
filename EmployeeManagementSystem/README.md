# Employee Management System

A Python-based Employee Management System built using Object-Oriented Programming (OOP).

## Features

- Employee CRUD Operations
- Salary Management
- Employee Search
- Employee Reports
- Bonus Calculation
- File Save & Load
- PostgreSQL Integration
- Unit Testing with Pytest

## Technologies Used

- Python
- PostgreSQL
- SQL
- Pytest
- Git
- OOP
